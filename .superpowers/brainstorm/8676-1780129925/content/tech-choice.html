Implementation Approach

How should we build these pages?

A

纯静态 HTML + CSS

手写 HTML/CSS/JS，无需构建工具。直接打开 index.html 即可浏览。最轻量，零依赖，适合放在 docs/ 目录直接部署到 GitHub Pages。

✓ 无构建步骤 · ✓ 极快加载 · ✓ GitHub Pages 原生支持
B

VitePress / Vite + Vue

Vue 驱动的静态站点生成器，内置 Markdown 支持、搜索、暗色主题。需要 Node.js 环境和构建步骤。

✓ Markdown 内容 · ✓ 内置搜索 · ✗ 需要 Node.js
C

Astro

现代静态站点框架，支持多种 UI 框架（React/Vue/Svelte），零 JS 默认，按需加载。适合内容型网站。

✓ 零 JS 默认 · ✓ 高性能 · ✗ 需要 Node.js
