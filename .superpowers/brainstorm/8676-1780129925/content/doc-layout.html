Quick Start

Get Orca Agent up and running in 5 minutes. Build from source, configure your provider, and start coding.

Overview

Orca Agent is a Rust-based AI coding agent with OS-level sandboxing, multi-provider support, and checkpoint recovery. This guide will walk you through installation and first use.

$ cargo build --release
# Builds to target/release/orca-agent
Tip
Add --profile release to skip the debug build and compile faster for production.
