Why Orca Agent?
🔐
OS-Level Sandboxing
Seatbelt on macOS, AppContainer on Windows, Landlock on Linux. Commands run isolated.
🧠
Semantic Capacity
CanonicalState tracks goals, constraints, and facts. 3-checkpoint evaluation prevents drift.
🔌
Multi-Provider
DeepSeek, Claude, OpenAI, plus any OpenAI-compatible provider (Ollama, Groq, vLLM...)
🔄
Checkpoint Recovery
Save session state to disk. Resume from any checkpoint. Never lose progress on long tasks.
