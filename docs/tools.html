Tools

Built-in tool reference for Orca Agent. Filesystem operations, command execution, version control, and web access.

Overview

Orca Agent includes 8 built-in tools for filesystem operations, command execution, version control, and web access. Tools are sandboxed based on their risk level.

Tool Description Sandboxed
read_file Read file contents No
write_file Write content to file No
glob Find files by pattern No
grep Search file contents by regex No
execute_shell Execute shell commands Yes
git Git operations (status, diff, log, add, commit) No
web_fetch Fetch URL content Yes
web_search Web search via DuckDuckGo Yes

read_file

Read the contents of a file at a given path. Returns the full file content as a string.

{
"name": "read_file",
"arguments": {
"path": "src/main.rs"
}
}

write_file

Write content to a file. Creates the file if it doesn't exist, overwrites if it does.

{
"name": "write_file",
"arguments": {
"path": "src/config.rs",
"content": "pub const VERSION: &str = \"0.1.0\";"
}
}

glob

Find files matching a glob pattern. Returns a list of matching file paths.

{
"name": "glob",
"arguments": {
"pattern": "**/*.rs"
}
}

grep

Search file contents using regular expressions. Returns matching lines with file paths and line numbers.

{
"name": "grep",
"arguments": {
"pattern": "fn\\s+main",
"glob": "*.rs"
}
}

execute_shell

Execute a shell command in the working directory. Output is truncated to prevent context overflow.

{
"name": "execute_shell",
"arguments": {
"command": "cargo test --workspace"
}
}
Sandboxed
Shell commands run with OS-level sandboxing. Execution timeout defaults to 120 seconds (configurable). Dangerous commands are blocked. Network access is denied by default.

git

Perform git operations. Supports common commands: status, diff, log, add, commit, branch, checkout, and more.

{
"name": "git",
"arguments": {
"subcommand": "diff",
"args": ["--staged"]
}
}

web_fetch

Fetch content from a URL. Returns the response body as text. Useful for reading documentation, API responses, or web pages.

{
"name": "web_fetch",
"arguments": {
"url": "https://docs.rs/tokio/latest/tokio/"
}
}
Sandboxed
Network requests go through the sandbox. Only HTTP/HTTPS URLs are allowed.

web_search

Search the web using DuckDuckGo. Returns a list of search results with titles, URLs, and snippets.

{
"name": "web_search",
"arguments": {
"query": "rust async runtime comparison"
}
}

Tool Name Resolution

When a model outputs an incorrect tool name, Orca uses a 5-step fuzzy matching process to find the intended tool:

  1. Exact match
  2. Case-insensitive match (Read_File → read_file)
  3. Hyphen normalization (read-file → read_file)
  4. CamelCase conversion (readFile → read_file)
  5. Prefix fuzzy match (read → read_file)

Legacy tool call formats are also supported: [TOOL_CALL] prefix, XML <tool> tags, and JSON code blocks.

Argument Repair

When a model outputs malformed JSON arguments, Orca runs a 6-stage repair pipeline:

  1. Direct parse attempt
  2. Control character removal
  3. Trailing comma removal
  4. Bracket balancing
  5. Extra closure stripping
  6. Double-encoded JSON detection
