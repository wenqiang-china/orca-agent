Provider Configuration

Configure LLM providers for Orca Agent. Supports DeepSeek, Anthropic, OpenAI, and any OpenAI-compatible endpoint.

Built-in Providers

Orca Agent ships with three built-in providers. Each requires an API key set as an environment variable.

Provider CLI Name Models API Key
DeepSeek deepseek deepseek-chat, deepseek-reasoner DEEPSEEK_API_KEY
Anthropic anthropic / claude claude-sonnet-4-20250514, claude-opus-4-20250514 ANTHROPIC_API_KEY
OpenAI openai gpt-4o, gpt-4o-mini, gpt-4.1, o1, o3, o3-mini OPENAI_API_KEY

DeepSeek

DeepSeek is the default provider, offering excellent performance at low cost.

$ orca chat --provider deepseek --model deepseek-chat
$ orca chat --provider deepseek --model deepseek-reasoner

Anthropic (Claude)

Anthropic's Claude models provide strong reasoning and code generation capabilities.

$ orca chat --provider anthropic --model claude-sonnet-4-20250514
$ orca chat --provider claude --model claude-opus-4-20250514
Tip
Both --provider anthropic and --provider claude work interchangeably.

OpenAI

OpenAI's GPT and reasoning models (o1, o3) are fully supported.

$ orca chat --provider openai --model gpt-4o
$ orca chat --provider openai --model o3

Custom Providers (OpenAI-Compatible)

Any provider that implements the OpenAI API format is supported via the --base-url flag or config file. This includes Ollama, Groq, Together AI, OpenRouter, Azure OpenAI, vLLM, LiteLLM, and Cloudflare Workers AI.

Provider Base URL
Ollama http://localhost:11434/v1
Groq https://api.groq.com/openai
Together AI https://api.together.xyz/v1
OpenRouter https://openrouter.ai/api/v1
Azure OpenAI https://{resource}.openai.azure.com/openai
vLLM http://localhost:8000/v1
LiteLLM http://localhost:4000
Cloudflare Workers AI https://api.cloudflare.com/client/v4/accounts/{id}/ai

Configuration

For persistent configuration, add a custom provider to your config.toml file:

provider = "custom"
model = "your-model-name"
[providers.custom]
api_key = "$YOUR_API_KEY"
base_url = "https://your-api-endpoint.com"

Examples

Ollama (local):

$ orca chat --provider openai --model llama3 --base-url http://localhost:11434/v1

Groq:

$ orca chat --provider openai --model llama3-70b-8192 --base-url https://api.groq.com/openai

OpenRouter:

$ orca chat --provider openai --model anthropic/claude-3.5-sonnet --base-url https://openrouter.ai/api/v1
