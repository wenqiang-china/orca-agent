Configuration

Orca Agent uses a TOML configuration file for all settings. CLI flags override config file values for the current session.

File Location

~/.config/orca/config.toml
Tip
Run orca config show to view your current configuration at any time.

Top-Level Settings

Key Type Default Description
provider string "deepseek" Active provider name
model string "deepseek-chat" Active model name
log_level string "info" Logging level (trace, debug, info, warn, error)

Provider Settings

Each provider is configured under [providers.<name>]. At minimum, an API key is required.

Key Type Default Description
api_key string (required) API key. Supports $ENV_VAR syntax
base_url string (provider default) Custom API endpoint URL
[providers.deepseek]
api_key = "$DEEPSEEK_API_KEY"
[providers.anthropic]
api_key = "$ANTHROPIC_API_KEY"
[providers.openai]
api_key = "$OPENAI_API_KEY"
# base_url = "https://api.openai.com" # optional custom endpoint

Sandbox Settings

The [sandbox] section controls OS-level command isolation.

Key Type Default Description
enabled bool true Enable OS-level sandboxing
exec_timeout_secs integer 120 Command execution timeout in seconds
max_exec_timeout_secs integer 600 Maximum allowed timeout value
network_policy string "denied" Network access: denied, restricted, full

Budget Settings

The [budget] section controls cost and iteration limits.

Key Type Default Description
max_session_budget_usd float 10.0 Maximum spend per session in USD
max_iterations integer 200 Maximum agent loop iterations
rate_limit_per_minute integer 60 Maximum API calls per minute

Context Settings

The [context] section controls context window management and checkpointing.

Key Type Default Description
max_context_tokens integer 128000 Maximum context window size
compress_threshold float 0.75 Trigger compression at this % of max tokens
max_checkpoints integer 10 Maximum number of stored checkpoints
use_flash_summary bool true Use flash summaries for context compression

Complete Example

provider = "deepseek"
model = "deepseek-chat"
[providers.deepseek]
api_key = "$DEEPSEEK_API_KEY"
# base_url = "https://api.deepseek.com" # optional custom endpoint
[sandbox]
enabled = true
exec_timeout_secs = 120
max_exec_timeout_secs = 600
network_policy = "denied" # denied | restricted | full
[budget]
max_session_budget_usd = 10.0
max_iterations = 200
rate_limit_per_minute = 60
[context]
max_context_tokens = 128000
compress_threshold = 0.75
max_checkpoints = 10
use_flash_summary = true
log_level = "info"
