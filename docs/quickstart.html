Quick Start

Get Orca Agent up and running in 5 minutes. Build from source, configure your provider, and start coding.

Overview

Orca Agent is a Rust-based AI coding agent with OS-level sandboxing, multi-provider support, and checkpoint recovery. This guide walks you through installation and your first session.

Prerequisites

Requirement Details
Rust toolchain 1.70+ (install via rustup.rs)
Git For cloning the repository
API Key At least one provider key (DeepSeek, Anthropic, or OpenAI)

Build from Source

$ git clone https://github.com/orca-agent/orca-agent.git
$ cd orca-agent
$ cargo build --release
# Binary at target/release/orca-agent
Tip
For faster development builds, omit --release. The debug binary is larger but compiles significantly faster.

Set API Keys

$ export DEEPSEEK_API_KEY="your-key"
$ export ANTHROPIC_API_KEY="your-key"
$ export OPENAI_API_KEY="your-key"
Security
Never commit API keys to version control. Use environment variables or a secrets manager.

First Run

$ ./target/release/orca chat
Orca v0.1.0 - AI Coding Agent
Model: deepseek-chat (deepseek)
Type your message, or 'quit' to exit.
> explain how this codebase is organized
(agent responds with codebase analysis)

TUI Mode

$ ./target/release/orca chat --tui

TUI mode provides a rich terminal interface built with ratatui. Navigate with keyboard shortcuts, scroll through conversation history, and monitor tool execution in real-time.
