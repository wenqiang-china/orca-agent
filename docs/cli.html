CLI

Command-line interface reference for Orca Agent.

Overview

Orca Agent exposes its functionality through a CLI with multiple commands. The general syntax is: orca <command> [flags].

Global Flags

Flag Short Description Default
--workdir -w Working directory .
--model -m Model to use (from config)
--provider -p Provider to use (from config)
--verbose -v Verbose logging false
--prompt Initial prompt (non-interactive) (none)
--tui Use TUI mode false
--base-url Custom API base URL (from config)

chat

Start an interactive chat session. This is the default command if none is specified.

# Interactive session
$ orca chat
# TUI mode
$ orca chat --tui
# One-shot query
$ orca chat -p "explain this code"
# With custom provider
$ orca chat --provider openai --model gpt-4o --base-url http://localhost:11434/v1

config

Manage configuration. Supports show, set, and reset operations.

# Show current config
$ orca config show
# Set a value
$ orca config set provider openai
# Reset to defaults
$ orca config reset

models

List all available models across configured providers.

$ orca models
Available models:
Provider: deepseek
- deepseek-chat (default)
- deepseek-reasoner
Provider: anthropic
- claude-sonnet-4-20250514
- claude-opus-4-20250514
Provider: openai
- gpt-4o
- gpt-4o-mini
- gpt-4.1
- o1
- o3
- o3-mini
Provider: custom (OpenAI-compatible)
- any model via base_url in config

resume

Resume a session from a saved checkpoint. Checkpoints preserve the full agent state including message history and tool results.

$ orca resume <checkpoint-id>

In-Chat Commands

During an interactive session, these slash commands are available. Commands are case-sensitive.

Information Queries

Command Args Description
/help List all commands with descriptions
/tools Show registered tools with name and description
/model Show current provider, model, and base URL
/context Show context window usage, compression threshold, and iteration stats
/cost Show accumulated cost and iteration count
/history [n] Show last n messages (default: 10)
/system Print current system prompt

Session Management

Command Args Description
/checkpoint Create a manual checkpoint
/clear Clear conversation history (requires confirmation)
/save [file] Export conversation to JSON. Default: .orca-sessions/<id>.json
/load <file> Load conversation from a JSON file
/undo Remove the last user message and its response

Conversation Control

Command Args Description
/compact Force context compression and report token savings
/system <text> Update the system prompt

Exit

Command Args Description
quit / exit / q Exit the session

Examples

# Show all available commands
> /help
# Show last 20 messages
> /history 20
# Save session to a custom file
> /save my-session.json
# Force context compression
> /compact
# Update system prompt
> /system You are a Rust expert. Always use idiomatic error handling.
